# GPS HQ (demo)

Live demo: https://codedbycb-afk.github.io/gps-hq-demo/

A phone app for a Cleveland house-flipping business. This copy runs on sample houses; the market numbers are real public Cuyahoga County sales records (12 months to Aug 31, 2026) for three ZIPs. The real app runs privately inside the client's own Google account.

Built by Twenty47 Marketing.
